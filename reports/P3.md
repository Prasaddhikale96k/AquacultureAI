  fade+scale, focus trap, Escape close, outside-click close, focus return and

### Limitations
- The live-run evidence uses a synthetic camera device, not a physical
  DroidCam; real lighting, focus and motion remain owner-QA items.
- Session timeline data is in-memory for the current browser session and is
  lost on reload; it is not a persisted analysis history.
- Detection counts are frame-level model output, not unique-fish counts.
- The camera setup popover is available only while the camera is on.
